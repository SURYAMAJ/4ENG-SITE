# 4ENG website

Sales and marketing website for 4ENG, built as a static Cloudflare Workers project. It has no application database, no Supabase dependency, and no server-side API.

## Project structure

```text
4eng-site/
├── src/index.src.html       Source page: layout, styles, copy and interactions
├── public/                  Deploy-ready static assets
│   ├── index.html           Generated by build.py; do not edit directly
│   ├── 404.html
│   ├── _headers             Security and cache headers
│   ├── assets/fonts/        Self-hosted Archivo and B612
│   └── assets/logo/         4ENG SVG and PNG brand assets
├── build.py                 Expands reusable diagrams, FAQ and site settings
├── wrangler.jsonc           Cloudflare Workers Static Assets configuration
├── package.json             Local preview, validation and deployment commands
└── DEPLOYMENT.md            Cloudflare and GoDaddy handoff instructions
```

## Local development

Requirements: Python 3, Node.js and npm.

```powershell
npm install
npm run build
npm run dev
```

Edit the public settings near the top of `build.py`:

- `SITE`: canonical marketing-site domain
- `EMAIL`: design-partner contact address
- `APP`: 4ENG application sign-up URL

Edit page copy and interactions in `src/index.src.html`. FAQ content lives in `build.py` because it is used for both visible content and FAQ structured data. Run `npm run build` after each source change.

## Validate and deploy

```powershell
npm run check
npx wrangler login
npm run deploy
```

`npm run check` rebuilds the generated site and performs a Cloudflare dry-run deployment. See `DEPLOYMENT.md` for custom-domain and GoDaddy nameserver steps.

## Contact form

The design-partner form validates in the browser, then opens a pre-addressed email draft in the visitor's mail app. Nothing is stored or transmitted by the website itself. This keeps the project frontend-only while retaining a clear lead-generation path.

## Brand and SEO

- Shared-stem logo package: Steel `#5980A6`, Navy `#1D2D3D`, Ink `#1D1F20`, Paper `#F2F2F3`
- Interface accents remain functional: CAD blue for selections, redline for changes and green for verified states
- Self-hosted, licensed fonts with no third-party font requests
- Responsive from 360 px upward, with dark theme, reduced-motion support and keyboard focus states
- Organization, WebSite, SoftwareApplication and FAQ structured data
- Open Graph image, favicon set, web manifest, `robots.txt`, `sitemap.xml` and `llms.txt`
- Security headers and immutable caching for versioned font assets

After launch, submit the sitemap to Google Search Console and Bing Webmaster Tools. Cloudflare Web Analytics can be enabled without changing the current Content Security Policy.
